# Mystery Protocol — Interactive Campus Map

A standalone browser map prototype for Brindavan College of Engineering.

## Run locally
Open `index.html` in a browser, or deploy this repository directly with GitHub Pages / Netlify / Vercel.

## Notes
- Uses OpenStreetMap tiles via Leaflet for the geographic base.
- 2D/3D-style toggle, checkpoint selection, route guidance, and local progress tracking.
- Checkpoints are intentionally configurable in `app.js`; do not claim a checkpoint is an exact building location until verified against campus footage / organiser ground truth.
